# The Atabeis Empire

A lightweight starter project scaffold for the "The Atabeis Empire" repository.

## Project structure

- `index.html` — landing page
- `styles.css` — styling
- `script.js` — page logic
- `assets/` — static media and images
- `docs/` — project documentation

## Quick start

Open `index.html` directly in a browser, or serve the project locally with a simple static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Notes

This repository was empty apart from the license and a minimal README, so this scaffold creates a simple starting point for future development.
